## 🤝 Contributing

Missing a solution that belongs here? **Contributions are welcome!**

If you've solved a Codeforces problem whose solution isn't present in this repo yet, feel free to open a pull request. Please follow the existing structure:

- Place the file in the correct difficulty folder (`A/`, `B/`, `C/`, etc.)
- Name the file after the **problem title** (e.g., `Watermelon.java`)
- Keep the code clean and readable
- Make sure it passes all test cases on Codeforces before submitting
